SuiteDock portable mode

While this file sits next to suitedock.exe, SuiteDock keeps its settings, its
download cache and its record of installed apps in the SuiteDockData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move SuiteDock with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\SuiteDock) instead.
If SuiteDockData can't be written (for example on a read-only drive), SuiteDock says
so and uses %APPDATA%\SuiteDock instead.
